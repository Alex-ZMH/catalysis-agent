# MD 传热、传质与动量输运

工作台「MD 热、质与动量传递」读取带列标题、同一采样行中同时包含位置、场量与有符号通量或剪切应力的表格：CSV、XLSX，或带标准标题的 LAMMPS fix ave/chunk、fix ave/time 文本输出。单独的普通轨迹、热力学日志或分离的场与通量文件不能直接计算；先按相同位置和采样时间整理成配对采样表。此分析本身不提交计算作业。

选择列、输入单位、方向与可选时间/空间窗口及空间分箱。先在选定窗口内对每个位置或空间分箱的场量求均值，以各位置等权线性拟合得到梯度；通量或应力对选中行等权求平均。显示原始数据、剖面、拟合线和计算值。时间窗口和空间窗口均含端点。

- 热传导：k = −mean(q)/grad(T)，单位 W/(m·K)。q 是归一化后的有符号热流密度，非总能流；输入文件应已按几何面积和实际热流路径处理。
- 传质：D = −mean(J)/grad(c)，单位 m²/s。浓度与通量需采用相同质量、摩尔或粒子数基准。J 应是针对所研究组分的扩散通量，参考系及对流项须由采样者定义和处理。
- 动量输运：动量通量 P 约定下 η = −mean(P)/grad(v)，柯西应力 τ 约定下 η = +mean(τ)/grad(v)，单位 Pa·s。应力和速度分量须对应同一剪切方向。

界面允许记录梯度或通量驱动方式；两者均使用实际场与通量列计算，不根据驱动方式虚构数据。可输出负值；零梯度无法除时给出提示。线性拟合是所选区域的结果，不自动声称体系已进入稳态。面积、周期双热流路径、采样归一化、热流参考系和组分的物理定义取决于原数据的生成设置，不由该工具猜测。

单位由用户明确指定，转换至 SI 后计算。输入的时间列仅用于窗口选择，不自动对非等时间间隔重加权。详细支持单位及列名在界面可见；单位不支持时需要先转为已支持单位。每次运行保留源文件、参数、来源行、结果与代码版本。上传来源作业号是用户手动标注，并非系统查询验证；项目中已调度的 MD 任务仍保留人工确认和 Slurm 回执。
