# v0.1 开发约定

## 仓库与数据目录

| 位置 | 职责 |
| --- | --- |
| `baselines/`、`scripts/frontend_baseline.py` | 固定前端标签对象、白名单、大小和 SHA-256；支持校验 Git 内容和已有前端工作目录 |
| `contracts/v1/` | 运行清单、内网配置、吸附与动力学的输入和结果、MD 与设备场的规范化输出。JSON Schema 采用 Draft 2020-12，引用由本地注册表解析 |
| `packages/contracts.py`、`packages/check.py` | 离线结构校验与命令行入口 |
| `packages/science/` | 四个科学方向的跨字段约束与候选结果复核 |
| `packages/agent/` | 运行清单、工件图、内容完整性；后续接项目身份与审批 |
| `configs/profiles/`、`requirements.lock` | 内网策略、资源盘点状态与使用过的依赖版本 |
| `tests/`、`docs/` | 现场可复跑的验收用例、工程约定和签收条件 |

本地服务入口为 `apps/server.py`，工作台扩展位于 `apps/web/`。数据根位于仓库外，例如 `D:/research-data/catalysis-agent/`。原件、参数和结果按内容指纹存入 `projects/<project_id>/raw/<sha256前两位>/<sha256>`，清单和索引存入 `projects/<project_id>/runs/<run_id>/`。文件名用于展示，读写路径由项目与工件映射确定。重复提交同一版本、来源、文件和参数可复用记录。解析或独立参考比较失败时，请求返回错误，运行历史只展示成功发布的记录。

Git 默认忽略未经允许的文件。新增源码、合成验收用例或契约需要按名称或目录核对暂存清单。实验原表、计算输出、模型权重、许可证密钥、赝势文件和备份留在受控存储。配置提交逻辑 ID 和状态；访问凭证由部署环境提供。

## 版本与交付

- `main` 记录审查后的里程碑。功能工作可使用 `codex/<主题>` 分支。每次提交核对已暂存路径和差异。
- 前端基线标签按 `frontend-baseline-vN` 递增，已签收标签保持原指向。基线、方法、数据契约、应用版本分别维护。
- 当前契约系列为 `contracts/v1/`；运行清单明确写入 `schema_version`。同一系列保留旧记录可读性；新增必填字段、改变数值或单位语义、缩窄已接受的记录集合时启用新主版本并提供旧版回读或迁移用例。仍在开发的契约按 Git 提交精确追溯。
- 每条运行记录绑定完整代码提交、方法标识和版本、配置工件、项目与操作员、UTC 时间、输入输出工件 ID 与哈希、质量状态及原因。科学输入中记录对应单位、模型和收敛或采样证据。输出可逆向追到本次实际输入。
- 应用版本使用 SemVer，候选版从 `v0.1.0-rc.1` 开始。候选版需完成可运行的服务链路，正式版以验收表的现场签收为准。本次建仓使用 Git 提交定位工程里程碑。

## 从契约到生产功能

1. 盘点内网测试节点和存储，建立项目身份、数据隔离、审计与只追加工件库。对接工作台时保留现有展示草案和分析运行的区分。
2. 接入 VASP 结果与实验 CSV/XLSX。记录源文件格式、原单位、规范化单位、参数和哈希，处理脏行、缺项、重复导入及失败恢复。
3. 实现真实吸附对照与模型拟合。对照独立能量手算或既有脚本，拟合按批次或工况留出、复核残差与可辨识性。记录输入不足和模型适用范围。
4. 接入 LAMMPS 和 VTU 文件，按声明单位还原时空坐标，验证点场和单元场的取样。完成工作台串联、内网端到端测试及数据恢复演练。
5. 重计算入口仅生成待人工确认的计划。v0.1 的工作进程没有集群提交能力，人工确认也不产生集群作业。节点与授权盘点完成后仍须另行确定未来调度能力。

## 当前进度与下一次验收

前端基线已冻结，VASP 吸附对照与实验 CSV/XLSX 拟合已通过从文件开始的合成数据工作台验收。已有结果可回到具体 XML、工作表和原始行，合成项目也已完成换目录恢复和独立复算。晶胞构建覆盖含真空恰好 50 Å 与超限的边界。

A5 已完成原始轨迹与网格文件的导入及合成样本工作台验收。LAMMPS 文本轨迹按步号和原子 ID 对照坐标、单位与周期边界。VTU 按网格关联、分量和物理坐标取样，分别对照点场和单元场的独立参考。两条链路的原件、参考和参数均可从结果追溯。下一次 A5 签收使用内网现场导出的脱敏原件和独立参考。轨迹之外的 thermo 时序文件尚待接入。现场项目隔离、恢复演练、算力与授权盘点按[验收表](acceptance.md)跟踪。
