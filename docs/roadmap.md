# 催化剂开发到工程应用总任务清单

开发主线为 DFT → MD → 工程应用。工作台提供各尺度的独立进入方式。上游交接、独立上传和已有数据导入均记录项目、对象、来源与工况。跨尺度传递时保留数值、单位、参考态、适用范围、运行 ID、代码版本和作业号。工作台直接展示计算输出及相关状态。

| 1 | 项目与数据管理 | 项目隔离、账户角色、审计、原件与分析产物、项目备份和恢复。复用 A1、A7 记录 | 样品与批次、工况版本、结构及文件分类、成员管理界面和项目内检索 |

| 3 | 任务与调度 | 人工确认、提交去重、Slurm 回执和 A6 合成提交验收 | 各求解器的命令行执行适配，随后接工作台排队、进度、取消、恢复、资源申请和真实作业关联 |

## 紧接的开发顺序

1. 已完成从 DFT 结果或独立结构生成显式配置的 MD 作业。V100 作业 1033 使用工作台生成的作业包运行，记录轨迹、热力学、末态、重启文件和 Slurm 作业号。[MD 作业配置](md-job.md)
2. 已接入实际 MD 输出的热力学曲线与指定原子组 MSD/扩散拟合。[MD 输出分析](md-analysis.md)；下一步接工作台运行控制。传热、跨界面传质和动量输运各自使用匹配的采样方式与边界，标明物理量的定义和单位。
3. 用经选定的有效物性和动力学关系配置工程边界与源项。反应器线可以直接从有效物性、工况及网格进入。RVE、FEM 的只读迁移评估供项目决策。[MLCC 模块盘点](mlcc-migration.md)

## 进入工作台的数据

| 起点 | 当前和后续入口 |
| --- | --- |
| DFT | 上传结构、VASP 计算结果或吸附研究包，按所选任务访问已有分析或构建功能 |
| MD | 在 VASP 运行里选一个最终结构，或单独上传结构配置作业。已有轨迹可独立导入 |
| 工程场 | 从已有 VTU 网格及结果开始。求解入口后续增加几何、网格、物性、边界、流量和源项 |

A1–A7 已有记录见[验收表](acceptance.md)。A5 和 A7 的现场签收等待脱敏数据。开发代码、版本与运行批次沿用 V100 的 `development/`、`releases/` 和 `jobs/<阶段>/<批次>/`。
