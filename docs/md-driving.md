# LAMMPS 可控边界驱动

在 LAMMPS 作业配置中，`transport_driving` 定义实际边界，`transport_sampling` 定义输出。两者独立；驱动设置、原始结构、力场、采样设置及 Slurm 计划一同保存。创建计划后仍须人工确认，恢复作业保留上游检查点与作业来源。驱动方向、区域及全部数值由项目配置给出，不使用固定的示范体系。

| 驱动 | 设置与输出含义 |
| --- | --- |
| 温度 | `thermostat_slabs` 指定轴、两个不重叠区域、热/冷端温度 K、Langevin 阻尼 ps 和随机种子；组内原子按区域更新。统计恒温器交换能量与空间温度和热流。目标温度是边界设置，实际温度梯度取自采样。 |
| 浓度 | `atom_swap_reservoirs` 指定两种或多种原子类型、两个区域及各物种的化学势 eV、交换频率、尝试数、温度和种子。半巨正则原子类型交换按粒子当前位置选择区域。化学势差控制储库条件，不保证浓度或梯度达到指定值；采样组分质量浓度及质量通量。 |
| 剪切 | `moving_walls` 指定法向轴、切向轴、两个不重叠区域和各壁的切向速度 Å/ps。壁原子由 `fix move` 驱动，并从流体积分组中排除；采样切向速度和对应剪切应力。法向边界使用非周期边界，当前方案使用正交盒；SLLOD 和变形三斜盒未包含在内。 |

采样输出及导入使用既有 `transport_profile.dat`、`transport_velocity.dat`、`transport_global.dat`、`transport_metadata.json`。沿所选法向采样时，应力分量和流向速度必须匹配，例如法向 z、切向 x 时使用 τxz 与 ∂vx/∂z；选择相同的单位、时间范围和采样组件。原始输出与边界设置、计划 ID、作业号和分析记录一同保留。外部表格与项目作业自动关联方式不同，页面分别标注。

全盒 `compute heat/flux` 除以盒体积得到全局密度，分箱热流为按原子能量和应力分配的局部近似；该值不自动扣除对流。应力是否含动能项和参考速度取决于采样设置；存在流动时应依据研究目的处理流动速度贡献。壁与储库条件可能使体系远离稳态，短时拟合值只是所选窗口内的输出；不自动证明稳态或作为材料物性。选择区域、温控参数、化学势和壁速度需要与具体力场、几何、温度和模拟尺度匹配。换成真实项目时应自行提供对应结构与力场。

数据及求解继续在 V100 内网，保留人工确认与提交去重。RVE/FEM 不随此功能迁移。

合成验收中，温度区域曾因暂时无原子而使 `zero_random_force=true` 的 Langevin 设置报错；后续新计划显式设置为 `false`。原设置和失败作业均保留，系统不自动更改用户选项。实际选择应结合体系和区域人口数决定。
