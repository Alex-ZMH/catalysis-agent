# v0.1 验收表

本次门槛是已冻结的可还原前端、独立本地仓库、可机读契约及可离线复跑的用例。运行契约验证器只会检查提供的记录。生产签收还需实际文件、实现及独立参考值。所有提交的测试输入均在用例内构造。

| 项 | 本次可执行的检查 | v0.1 发布签收动作和判据 |
| --- | --- | --- |
| 基线 | 校验标签对象、34 个文件的路径、字节数和 SHA-256，可与原前端逐一比较 | 从 Git 标签还原界面；改动前端时复跑全景 → 示范 → 工作台与参数带入体验 |
| A1 内网与项目隔离 | 配置拒绝外发、联网提交和未知策略；清单拒绝跨项目工件、路径型 ID；本地注册表解析契约 | 使用两个身份和两个项目测试读写隔离；拒绝越权请求；抓取内网测试运行的出口及审计证据 |
| A2 吸附 | 受控输入覆盖体相、裸表面、吸附构型及气相参考；复核计量、能量定义、收敛性和方法可比性；不合格构型带原因 | 两组经脱敏的真实对照，各含至少两个位点。相同定义下与独立参考的差值 ≤ 0.001 eV/吸附单位；不相容或未收敛的结果不得进入有效排序。这个阈值衡量软件算术一致性 |
| A3 动力学 | 对 Arrhenius 和初始速率幂律检查候选参数、训练设计和观测值的一致性；处理正值域、独立性与可辨识性 | 由实际拟合器对无噪声合成数据盲算，可辨识的非零参数相对误差 ≤ 0.1%；零值使用预先声明的绝对容差；真实数据按预先约定的留出方式与测量不确定度验收 |
| A4 数据质量 | 用例包含单位、重复标识、缺项、非有限值或引证不一致的拒绝路径 | 对破损原文件、重复导入、单位转换、缺列、秩亏和部分失败逐项给出可定位的诊断；核查原始文件哈希 |
| A5 MD 与设备场 | 核对规范化记录中的轨迹和物理量、网格关联、场分量及参考剖面 | 从真实 LAMMPS dump/时序、VTU 文件开始。逐帧比对步号、原子 ID、坐标、单位及周期边界；A–B 线在同一坐标、同一关联和分量下与独立参考逐点比较，预先约定容差、插值和域外点规则 |
| A6 调度和人工确认 | 契约允许四种轻量分析或导入操作；提交类动作以及把审批改成自动执行的配置应失败 | 对服务重复点击、并发请求、重试、恢复和人工确认做审计；集群提交次数为 0 |
| A7 证据与恢复 | 检查哈希和大小、清单内引用、跨项目、环路、缺失输入以及合成数据来源；命令行可将候选结果绑定到运行清单 | 在另一内网目录恢复真实项目，核对原始数据、配置和结果 SHA-256；复现同一分析并由数据负责人签收 |

本次签收覆盖表中“本次可执行的检查”。A1–A7 的发布签收动作仍待服务实现和现场验证，合成输入的通过记录独立保留。
