# 设备 VTU 导入与线剖面

设备导入读取单个 VTU 非结构网格中的坐标、连接关系、点字段和单元字段。可以只提交网格，也可以附加线剖面选项、独立参考 JSON，或同时提交两者。仅导入网格时，结果包含网格与字段清单。

## 导入选项

以下选项为同名点字段和单元字段分别声明单位，并指定从 A 到 B 的六个等距采样点。字段通过 `association` 和 `name` 共同定位。分量索引从 0 开始。

```json
{
  "length_unit": "m",
  "field_units": {
    "point": {"T": "K"},
    "cell": {"T": "K"}
  },
  "profiles": [
    {
      "a": [0.25, 0.25, 0.5],
      "b": [1.75, 0.25, 0.5],
      "field": {
        "name": "T",
        "association": "point",
        "selection": {"kind": "component", "index": 0}
      },
      "count": 6
    }
  ]
}
```

- `length_unit` 和 `field_units` 用于补充 VTU 中缺失的 `Unit` / `Units` 元数据。若同时提供原单位和显式声明，两者必须一致。坐标、字段和参考值均按声明的单位解释，无自动单位换算。无量纲字段可使用 `"1"`。
- 端点必须是网格坐标系中两个不同的三维点。采样位置为 `(1 − f)A + fB`。
- `count` 是包含两端的样本数，至少为 2。也可用 `fractions` 替换 `count`，提供从 0 严格递增到 1 的小数数组，例如 `[0, 0.2, 0.4, 0.6, 0.8, 1]`。
- 单次导入的所有剖面最多合计 10,000 个样点，`count` 与 `fractions` 共用这项预算。程序会先检查总数，再生成采样列表。
- 对至少有两个分量的字段，可用 `{"kind": "magnitude"}` 计算欧氏模长。

## 单元定位和取值

采样支持 VTK 四面体（10）、体素（11）和六面体（12）。程序先用物理坐标下的单元包围盒树缩小候选范围，再用单元参考坐标判定是否包含采样点。四面体采用重心坐标，体素和六面体采用八节点三线性形函数。六面体可有仿射斜切，也可有满足逆映射收敛条件的非仿射变形。退化、反转、严重病态或超出逆映射支持范围的单元会报错。剖面请求遇到其他 VTK 单元类型也会报错，包括混合网格中的未支持类型。仅查看网格字段时，可导入读取器支持的其他单元类型。

点字段用所在单元的形函数插值。单元字段直接取该单元的值，跨单元可能跳变。先得到完整分量，再选择分量或计算模长。边界包含在采样域中，浮点边界判定留有舍入容差。落在共享面、边或顶点的样点采用 VTU 单元顺序中索引最小的包含单元。网格外或空隙中的样点返回 `null`，无外推。

## 独立参考 JSON

将独立求解、解析计算或实测得到的对照值放在单独的 JSON 文件中。根节点须为包含 `length_unit` 和 `profiles` 的对象，`profiles` 须为剖面对象数组。各层对象中的键必须唯一，数值须有限。仅由参考定义的剖面也适用 10,000 个样点的预算。以下示例为两个相邻单元中的同名点、单元温度字段。六个等距样点均避开共享界面。与以下参考一起上传时，可从导入选项中省略 `profiles`，只保留长度和字段单位。

```json
{
  "length_unit": "m",
  "profiles": [
    {
      "a": [0.25, 0.25, 0.5],
      "b": [1.75, 0.25, 0.5],
      "field": {
        "name": "T",
        "association": "point",
        "selection": {"kind": "component", "index": 0}
      },
      "fractions": [0, 0.2, 0.4, 0.6, 0.8, 1],
      "unit": "K",
      "values": [302.5, 305.5, 308.5, 311.5, 314.5, 317.5],
      "absolute_tolerance": 0.000001
    },
    {
      "a": [0.25, 0.25, 0.5],
      "b": [1.75, 0.25, 0.5],
      "field": {
        "name": "T",
        "association": "cell",
        "selection": {"kind": "component", "index": 0}
      },
      "fractions": [0, 0.2, 0.4, 0.6, 0.8, 1],
      "unit": "K",
      "values": [315, 315, 315, 335, 335, 335],
      "absolute_tolerance": 0.000001
    }
  ]
}
```

若省略导入选项中的 `profiles`，程序从参考 JSON 提取端点、字段选择和采样分数，剖面仍由 VTU 网格计算。若显式提供 `profiles`，每条参考须唯一匹配一条计算剖面。匹配使用有方向的 A、B 端点、字段位置、字段名、取值方式和完整的采样分数序列，数值须相等。两份列表可采用不同顺序，结果按计算选项顺序输出。额外的计算剖面可以没有参考。

每条上传的参考至少需要一个数值，并应按 `fractions` 的顺序提供样本值。长度和字段单位须一致，且每个样点的 `null` 掩码须一致。所有有效样点，包括两端之间的样点，都须满足 `|计算值 − 参考值| ≤ absolute_tolerance + relative_tolerance × |参考值|`。两项容差均须为非负有限数，相对容差省略时为 0。任何不匹配都会中止导入。工作台可展示计算值、参考值、绝对误差和缺失掩码，并提供独立参考文件的下载链接。
