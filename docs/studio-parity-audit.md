# 电催化研究助手的计算与可视化验收

2026-11-22 在本机 8773 研究助手和 V100 的 CPU 分区完成。参考版本为 MLCC Studio `6d53ed37e95ef43a676ddfac85fb859523bbe2a3`。本机 8771 是原有文件分析服务，8772 是静态展示。

## 真实计算

从桌面账号发出一次自然语言请求，模型选择 `run_ni_reference`。计算节点提交 ABACUS v3.10.1 作业。模型随后调用 `query_abacus_scf`，发布输入结构 POSCAR、原生日志的文本副本和摘要。对话保存在「镍参考单点 · V100 实测」。

| 核查项 | 站点回执 |
| --- | --- |
| 体系 | fcc Ni 单原子原胞，a = 3.52 Å，初始磁矩 0.6 |
| 方法 | 共线自旋 PW/PBE，45 Ry，Gamma 中心 2×2×2 网格，高斯展宽 0.02 Ry |
| 作业 | Slurm 1064，cpu 分区，COMPLETED，退出码 0:0，耗时 4 秒 |
| 资源 | 1 个进程、每进程请求 1 CPU、无 GPU、2 GiB、限时 5 分钟。Slurm 记账分配 2 个 CPU |
| 原生收敛证据 | `charge density convergence is achieved` |
| 原生总能量 | `!FINAL_ETOT_IS -4191.075098532237 eV` |

该单点用于链路验收。活性结论还需表面与吸附模型、能量参考和参数收敛研究。专用自定义单点入口支持 Ni、O、Ca、Zr；其余站点能力以实际运行时的资源、方法和输入合同为准。本次未提交 VASP 作业。

另一段真实对话使用 HER 自由能工具。在 −0.08 V vs RHE、ΔG(H*) = 0.21 eV 时，两步 ΔG 分别为 +0.13 和 −0.29 eV。助手发布了自由能 SVG 与 CSV。

## MLCC 结果预览

本仓的科学预览器、派生资源服务与结果标签管理沿用上述版本。科学结构、轨迹、体数据与电子结构组件沿用参考代码；本地扩展了对话与附件正文的 Markdown 排版。工作台通过本机账号鉴权读取原件、派生清单与资源，PDF 字体和解码器随前端构建。

| 功能 | 实际覆盖 |
| --- | --- |
| 三维结构 | CIF、POSCAR/CONTCAR、XYZ、PDB、SDF；保留晶胞、显示样式和原子选择 |
| 轨迹 | ExtXYZ、XDATCAR、LAMMPS dump；帧切换和播放 |
| 体数据 | CUBE、CHGCAR、ELFCAR；等值面和阈值 |
| 电子结构 | EIGENVAL 能带、DOSCAR 态密度；费米参考和交互读数 |
| 附件 | 位图、安全 SVG、沙箱 HTML、CSV/TSV、文本、JSON、Markdown、PDF、DOCX/PPTX 内容提取 |
| 面板 | 从聊天附件打开右侧模态面板，手机全宽查看，支持文件引用、多标签和原件下载 |

- 对照 MLCC 原版构建与电催化工作台。原版公开入口的主脚本和样式与该提交按 `/mlcc/` 构建的文件逐字节一致。Chrome 在 1440 × 900 和 390 × 844 两种视口测得两版输入框、历史栏及结果面板几何一致。桌面结果面板宽 1100 像素，手机面板宽 390 像素。两边均通过附件打开面板，背景不能接收输入，文件选择、键盘切换标签、删除标签、全屏和关闭操作一致。左侧对照使用原版附带的 BaTiO₃ 格式样本，右侧使用已保存的 Ni 作业 1064。
- 在隔离的本机实例对 23 个 MLCC 格式夹具核对下载字节，8 类派生清单及全部引用资源通过鉴权、MIME 和长度检查。在 Chrome 逐个打开 23 个附件，核对相应画布、科学图、表格、文档或图像节点，检查报错状态。移动窗口 390 × 844，结果面板匹配视口。在浏览器实际操作了轨迹步进和播放、等值面阈值、能带键盘读数、PDF 缩放，并从真实作业对话打开了镍结构和原生日志。
- 另外 17 个工程工件通过 MLCC 原有大文件验收。15 个由 worker 自动收集。32 MiB 下载逐字节哈希核对，约 16 MiB 的 CUBE 返回可用等值面清单与资源。Chrome 也核对了全部 17 项的预览或下载提示，包括 AVIF、HTML、Markdown、长 CSV 和超限文件。
- 从 `apps/research` 执行 `npm ci`、`npm run build`、`npm test`。当前研究服务套件 176 项、前端预览套件 16 项通过。此计数只覆盖该研究入口。
- 上述格式夹具用于验证渲染。实际镍作业发布的是结构、日志和摘要。XLSX、VTU、XDMF、HDF5 沿用 MLCC 结果面板的下载处理；8771 文件分析服务另有 XLSX/VTU 专用分析。Office 内联显示文本和表格，Markdown 可切换阅读与原文，超出预览上限的原件可下载。

## 复现入口

双击仓库根目录的 `start.command`。在最近对话里选择「镍参考单点 · V100 实测」，点 POSCAR 打开三维结构，点 running_scf.txt 核对原生日志。选择「HER 自由能 · 模型实测」可打开自由能图与数值表。
